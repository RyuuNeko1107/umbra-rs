# ISSUE-053: `union_rings` が自己接触を含む配置で穴を誤った外環に割り当て、領域を捏造する

## 背景（実測された欠陥）

ISSUE-045 残件「要確認 7（後継選択の反例未構成）」を詰めるため、**ランダム化差分探索**を行った。
独立オラクル＝「入力リング群の even-odd 内外を点で直接評価した値」と、`union_rings` の出力多角形
（外環 ∧ ¬穴 の OR）の内外を、格子上の多数の点で突合する（境界近傍の点は除外）。

探索空間を「格子 0..5・リング 2〜5 本・頂点 3〜8（自己交差・自己接触を許す）」へ広げたところ、
**ベースライン（無変異）自体が 30 万件中 2 件で不一致**になった。最小化した反例は次の 2 つ。

### 反例 C（4 リング）

```
[(1,4), (3,4), (3,5)]
[(3,3), (5,5), (3,5)]
[(2,2), (3,3), (1,4)]
[(3,0), (3,4), (1,3), (2,2), (2,4)]
```

出力（2 多角形）:

```
poly0 outer: (3,5) (1,4) (1.4,3.2) (1,3) (2,2) (2.4,2.4) (3,0) (3,3) (5,5)
poly1 outer: (2,3.5) (2.111…,3.555…) (2,4)
poly1 hole : (1,4) (3,4) (2.111…,3.555…) (2.142…,3.428…) (2,3.5)
```

**`poly1` の穴が外環より大きい**（穴は `(1,4)` や `(3,4)` を含むが、外環は `x∈[2,2.11], y∈[3.5,4]` の
微小三角形）。`rings[1..]` は `rings[0]` の内部でなければならないという**出力構造契約の破れ**である。
結果として、本来 `poly0` に属すべき穴がどの多角形にも効かず、
点 `(1.6731, 3.7417)` / `(2.1731, 3.7417)` が「どの入力リングの even-odd 内部でもない」のに
出力では内部になる＝**存在しない領域を返している**。

### 反例 D（3 リング）

```
[(4,1), (4,0), (2,0), (3,2), (4,0), (0,1), (4,3), (0,0)]   ← (4,0) を 2 度通る自己接触
[(4,0), (3,0), (0,4)]
[(2,0), (2,1), (0,1)]
```

同様に、点 `(1.6731, 1.2417)` / `(2.1731, 0.7417)` で `want=false / got=true`。
出力には外環 3 つがあり、そのうち微小な外環 `(2.222…,0.444…) (2.285…,0.571…) (2,0.5)` に
それより広い穴が割り当たっている。

いずれも**契約内の入力**である（doc: 「各入力リングの充填規則は even-odd」「自己交差入力を許容」）。

## 影響

- `union_rings` の**出力構造契約**（`rings[1..]` は `rings[0]` の穴）が、退化配置で破れる。
- 面積が過大になる（捏造した領域ぶん）。`partial_limit`（部分食域＝帯 ∪ morning lune ∪ evening lune）は
  3 領域が**同一の limb 交点で接する**配置を実際に作るので、同種の退化に当たりうる。
  現行の実日食テスト（2024-04-08 の中心線 194 点全点内包）は通っているため、**実害が観測された
  日食はまだ無い**が、契約違反そのものは実在する。
- ISSUE-045 の「要確認 7」は後継選択の**反例未構成**を根拠に許容していた。本探索で
  後継選択の生存変異 2 件（`back` の符号・`diff` の符号）にも反例が見つかっており（下記）、
  その許容根拠は失効する。

## 既知の判別配置（要確認 7 の決着材料）

同じ探索で、`docs/reviews/mutation-polygon-union.md` §B の生存 5 件のうち 2 件を撃つ配置が得られた。

| 変異 | 判別配置 |
|---|---|
| `back = (-din[1]).atan2(-din[0])` の第 0 引数の `-` 削除 | `[(1,3),(4,3),(1,6)]` / `[(3,3),(3,1),(0,1),(3,2),(2,3),(2,2)]` / `[(1,3),(2,0),(1,2)]` |
| `back - dout[1].atan2(dout[0])` → `+` | `[(1,3),(0,0),(2,2),(2,0),(3,3)]` / `[(2,1),(0,0),(2,0),(1,1)]` |

残り 3 件（`back` 第 1 引数の `-` 削除・`diff < d` → `<=` / `==`）は、探索でベースラインと
同じ配置でしか落ちず、**本 issue の欠陥を直した後に再探索**して判定する。

## 目的

退化配置（自己接触・複数リングが同一頂点で会合）でも、`union_rings` が
**出力構造契約を満たし、入力の even-odd 和と点ごとに一致する**ようにする。

## 確定仕様

1. **点ごとの一致（headline）**: 出力の内外（外環 ∧ ¬穴 の OR）は、境界から離れた任意の点で
   「いずれかの入力リングの even-odd 内部」と一致する。
2. **構造契約**: 各多角形の `rings[1..]` は `rings[0]` の内部にある（穴の面積 < 外環の面積・
   穴の全頂点が外環の閉内部）。既存契約（外環 CCW・穴 CW・非閉・外環の面積降順）は維持。
3. **点を捏造しない**（既存契約）: 出力頂点は入力頂点か入力辺同士の交点。
4. 既存の非退化入力に対する出力は**不変**（union/geojson の既存テストが回帰ガード）。

## 非目的

- 平面 (lon,lat) 近似そのもの（反子午線は ISSUE-052 で解決済み・極は据え置き）。
- 厳密有理数演算への作り替え。量子化 1e-9° の方針は維持する。

## 受け入れテスト戦略

- 反例 C・D を**決定的テスト**として固定し、§確定仕様 1・2 を縛る。期待値は
  **点オラクル（入力リングの even-odd）から導出**し、実装出力からは取らない。
- **ランダム化差分テスト**（固定シード・有界反復）を追加し、格子上のランダム配置で
  §確定仕様 1・2 を縛る（探索空間＝格子 0..5・リング 2〜5・頂点 3〜8）。
- 既存 union 40 本・geojson 45 本・path_limits/path_geojson が回帰ガード。

### 実装

手順 7（穴の帰属）を、**空洞側代表点 1 点のプローブ**から**穴リング全頂点の閉内部包含**へ置換した
（`crates/umbra-geo/src/clip.rs`）。

- 穴 H が外環 O に属す条件を `|O| > |H|`（必要条件）かつ **H の全頂点が O の閉内部**（内部または境界上）とし、
  満たす外環のうち**最小面積**のものへ割り当てる（入れ子＝穴の中の島は従来どおり扱える）。
- 境界上の判定は新設の `point_in_or_on`（共線＋パラメータ範囲で辺上を先に判定し、外れたら `pip`）。
  穴の頂点が外環の頂点・辺に**乗る**（点接触・共有辺）配置で開内部判定が落とす問題を避ける。
- 含む外環が 1 つも無い CW 環は**穴として採用しない**（非有界面の境界成分＝偽の環）。
  幾何的に H ⊂ O なら必ず |O| > |H| なので、正しい外環が面積条件で落ちることはない。

**実装レビュー（別エージェント）の important 指摘 1 件に対応**: 初版には「頂点包含で候補が無ければ
従来のプローブ規則へ落ちる」退避経路があり、レビューは「本 issue が潰した弱い規則の再導入であり、
どのテストも通らない」と指摘した。**到達可能性を実測**（ランダム退化配置 30 万件・union 52 本・
実日食 path テスト 61 本で到達ゼロ）したうえで**削除**し、規則を一本化した。

### 要確認 7（ISSUE-045 残件）への影響

- 修正**前**に見つかった判別配置（`back` 第 0 引数の符号・`diff` の符号）は、修正**後**は判別力を失った。
  すなわちあれらは後継選択の誤りではなく、**本 issue の穴割当欠陥が露出していた**ものだった。

- 残る 4 件（`back` 第 0/第 1 引数の `-` 削除・`diff < d` → `<=` / `==`）は、修正後の実装では
  20 万件規模の探索で反例が出ない。**要確認 7 は「5 件・反例未構成」→「4 件・反例未構成」へ縮小**。
