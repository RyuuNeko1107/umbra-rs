## 目的と入出力

- **目的**: ベッセル要素（多項式 ISSUE-022 / 直接供給 ISSUE-037）から、**いずれかの時刻に部分食以上が
  見える地表点の集合**の外周を閉じた `GeoPolygon`（外環＋必要なら穴・反子午線跨ぎは MultiPolygon）として返す。
- **入力**: `BesselianSource`（x, y, d, μ, l1, l2, tan f1, tan f2）、全球接触 P1/P4（§8・部分食区間 [P1,P4]）、
  `PathOptions`（`include_limits`・`split_antimeridian`）、WGS84。
- **出力**: `EclipsePath.partial_limit: Option<GeoPolygon>`。中心食/部分食を問わず部分食域は存在しうる
  （部分食 only の日食でも `partial_limit` は Some になりうる＝中心食限定の `center_line` とは独立）。
- **単位/時刻系/フレーム**: §8 と同一（角度 rad、ベッセル長 Re、FundamentalPlane〔影軸 z・x̂=東・ŷ=天の北射影〕、
  地表点は WGS84 測地座標へ）。時刻は各境界点の TT（必要なら UTC 併記は後続）。

## 数式（第一原理・番号は本節内ローカル）

### 11.0 部分食域の定義

地表点 P=(ξ,η,ζ)（WGS84 上）は時刻 t に**部分食以上**を見る ⇔ 半影内:
```
(ξ − x)² + (η − y)² ≤ L1(ζ)²        L1(ζ) = l1 − ζ·tan f1
```
等号が半影縁（P 接触＝部分食の開始/終了）。部分食域 = `⋃_{t∈[P1,P4]} { P : 上式 }` の地表射影。
その**外周**が `partial_limit`。外周は次の 2 曲線族が交互に連なって閉じる:
**(A) 南北半影限界（昼面の包絡）** と **(B) rise/set 曲線（terminator 上の半影縁）**。

### 11.1 南北半影限界（昼面の包絡）— 式 11.1

部分食域の南北端は、移動する**半影**縁の包絡。各縁点 P は §8 限界線と同一の 2 条件を満たす（半径を
本影 L2 から半影 L1 に替えるのみ）:
- **(1) 錐exact（自己整合ζ）**: `(ξ−x)²+(η−y)² = L1(ζ)²`、`L1=l1−ζ·tan f1`（ζ は P 自身）。
- **(2) 包絡（路限界方向）**: 軸からのオフセットが `rel` に直交。

> 実装: 既存 `axis_intercept::solve_limit_edge` は半径に本影 `(l2, tan f2)` をハードコードしている。
> **半径 `(radius_l, tan_f)` を引数化**して半影 `(l1, tan f1)` でも解けるよう一般化する（本影限界 M9.4 は
> `(l2, tan f2)` を渡す呼び出しに退化）。不動点反復・WGS84 楕円体投影・南北割当は M9.4 と完全同一。

**昼面限定の注意**: 半影は大きく（l1 ≈ 0.53 Re）、|gamma| が大きい日食では半影限界が地表（昼面 ζ>0）を
外れて terminator（ζ=0）に達する。半影限界は **ζ>0 の昼面でのみ存在**し、ζ→0 で rise/set 曲線（11.3）へ
連結する。`solve_limit_edge` が `RootNotBracketed`（縁が地表を外す）を返す端が連結点の近傍。

### 11.2 terminator（日の出入り境界）— 式 11.2（**WGS84 厳密**・要確認#2 解決）

基本面 ζ=0 の地表点（太陽が地平＝日の出入り）の軌跡。`surface_point_for_fundamental` の残差
`r(ζ)=ρcos²+(ρsin/(1−f))²−1`（子午線楕円拘束）に ζ=0 を代入すると、px=−η sin d・py=ξ・pz=η cos d より
```
ξ² + k·η² = 1,      k = sin²d + cos²d/(1−f)²        （WGS84 terminator 楕円・基本面 (ξ,η)）
```
（球 f=0 で k=1 ⇒ 単位円。扁平 f>0 で k≥1 ⇒ η 方向に縮む楕円＝極扁平）。**球近似（k=1, 単位円）は
中心線・限界線の WGS84-exact パイプラインと不整合**（球面上に置いた点を WGS84 前方射影で戻すと ζ≠0、
~Re·f≈21 km の残差）になり往復オラクルが緩むため、本節は **terminator を上記楕円で厳密化**する（要確認#2 解決）。

### 11.3 rise/set 曲線（terminator 上の半影縁）— 式 11.3（**WGS84 厳密**）

時刻 t に「部分食の接触が日の出/日没ちょうどに起こる」点 = 半影縁 ∩ terminator（ζ=0）。基本面で **円**
（半影縁）∩ **楕円**（terminator・11.2）を厳密に解く:
```
楕円（terminator）:  ξ² + k·η² = 1                       （k = sin²d + cos²d/(1−f)²）
円（半影縁・ζ=0）:   (ξ−x)² + (η−y)² = l1²               （ζ=0 で半影半径は L1(0)=l1）
```
2 二次曲線の交点（幾何的に通常 ≤2）。楕円から `ξ = ±√(1−k·η²)`（|η|≤1/√k）を円へ代入した η の 1 変数
残差を、既存の粗走査＋Brent（`descending_sign_change_bracket`＋`brent_root`・降順走査機構）で根求めし、
各根 (ξ,η) を `fundamental_to_geodetic(ξ,η,0,d,μ)` で測地座標化する。**点は 11.2 楕円上にあるので WGS84
前方射影で ζ≈0 へ往復一致**＝中心線/限界線と同じ WGS84-exact オラクルで検証できる（球近似の不整合を排除）。

t を [P1,P4] で動かすと 2 根が 2 曲線（朝側・夕側 limb）を描く。P1・P4 では円が楕円に接し交点 1 点（外周の
尖点＝半影が地球に最初/最後に触れる点）。**rise/set/begin/end の 4 分類は出力ラベル（metadata）であり、
外周ポリゴン自体には不要**（要確認#1 解決）＝外環は 2 根曲線の**両方**（朝側 limb 弧・夕側 limb 弧）を使う。
朝/夕の別は経度の subsolar 点に対する東西（自転で先行/後行する側）で決め、begin/end は半影の進入/退出
（in-plane で半影が点を覆い始める/終わる）で決める（必要なら後続でラベル付け）。

### 11.4 外周ポリゴンの構成 — 式 11.4（**リボン法**・位相保存・要確認#3 の方針確定）

外環 = **昼面の南北半影限界**（11.1・(3c-i) `trace_penumbral_limits`・**lockstep**＝北[i]/南[i] が同一サンプル時刻の
対）を `北限界(P1→P4 時刻順)` ++ `南限界(P4→P1 逆順)` で繋いだ**帯状の単純多角形**とする。北限界が南限界の北を保つ
（lockstep の北南割当）ので自己交差せず、umbral path（中心線）は半影帯の内側に確実に内包される。

**方位ソートからの是正（重要・実 2024 で破綻）**: 当初は全境界点（半影限界＋rise/set limb）を最大食点まわりの大圏
方位でソートして外環化する設計だったが、**部分食域は実際には star-shaped でない**（実 2024 は太平洋〜欧州に跨る
巨大領域で、中心線北東端が方位ソート外環の外に落ちた＝方位ソートは限界線の時系列＝帯の位相を壊す）。リボン法は
限界線の時系列順を保つので位相が正しい。4 曲線ステッチ（北限界→夕 limb→南限界→朝 limb の端点連結）は limb 端の
接合が geometry 依存で脆く、v1 では採らない。

**limb（rise/set）bulge の扱い — (3c-iii) 確定（terminator 連結）**: 部分食域は半影帯の端を terminator（日の出入り）
まで張り出す bulge を含む。各サンプル時刻 t で南北縁を次のように定める（11.1 の「ζ→0 で rise/set 曲線へ連結」の実装）:
- **北縁** = 昼面包絡 `solve_limit_edge(l1,tan f1, sign=+1)` が解ければそれ（昼面 ζ>0 の半影限界）。半影縁が昼面を
  外れて解けない（`RootNotBracketed`／未収束＝`Ok(None)`）端区間では、**terminator 交点**（`cone_terminator_intersections`・
  11.3 の円∩terminator 楕円・ζ=0）のうち**高緯度側**で連結する。
- **南縁** = 同様に `sign=−1` の昼面包絡／解けなければ terminator 交点の**低緯度側**。
- 北[i]/南[i] は **lockstep** 対（両縁が昼面包絡 or terminator のいずれかで埋まったサンプルのみ採用）。

これで外環は **昼面包絡が欠ける端区間で terminator まで張り出す**（genuine な limb bulge）。terminator 点は ζ=0 ゆえ
半影縁条件 `面内距離=|l1−ζ·tan f1|=l1` を**厳密に満たす**（11.5「頂点正当性」は terminator 頂点でも成立＝捏造点でない）。
昼面包絡（時間方向の路限界包絡）と terminator 交点（瞬時の日の出入り境界）の連結点は ζ→0 で両者が一致へ漸近するため
位相破綻しない。**到達範囲（重要・実 2024 で確認）**: この「昼面包絡が**無い**サンプルだけ terminator で補う」連結は、
v1 リボンより limb 方向に広いが、**中心線全点の平面 point-in-polygon 内包は達成しない**。実 2024 では中心線の早期端
（U1 近傍・~6.7°S・sunrise）は、その時刻に昼面南北包絡が**存在する**（軸の東側）一方、領域の西端境界は**朝側 rise/set
terminator limb**（[P1,P4] 全域で追跡される morning limb）であり、本連結はそれを織り込まないため、平面 PIP で帯の西
外に落ちる。**真の west/east 境界＝morning/evening terminator limb を [P1,P4] 全域で追跡する 4 曲線境界**（北限界＋夕 limb＋
南限界＋朝 limb）が full containment には必要だが、これは設計が v1 で「脆い」として回避したステッチであり **後続へ繰り延べ**
（本スライス (3c-iii) は端区間連結による genuine bulge までを成果物とし、full containment は 4 曲線境界の後続スライスに委ねる）。
**残る近似**: 端部 limb 過小被覆（中心線の U1/U4 近傍端点は帯外になりうる）＋ terminator 弧の粒度は `sample_interval_seconds`
律速。反子午線跨ぎ MultiPolygon は (3d) 後続（conventions §11 で近似を明記）。

- 反子午線（|Δlon|>180）跨ぎ MultiPolygon 分割・環向き RFC 7946（外環 CCW・穴 CW）正規化は **(3d)** GeoJSON 化で扱う
  （`partial_limit` 自体はリボンの単一外環として持つ）。境界点 3 未満（半影限界が昼面にほぼ無い極小部分食）は `None`。

### 11.5 検証戦略（弱オラクルの補強）

外環の頂点の正しさと領域の妥当性を多層で縛る:
- **頂点の正当性**: 各外環頂点は半影縁条件（軸からの面内距離 ≈ `|l1−ζ·tan f1|`・自己整合ζ）を前方射影で機械精度で満たす
  （リボン頂点は全て (3c-i) 半影限界点）。
- **包含（partial ⊃ umbral path）**: 中心食では `partial_limit` が中心線・最大食点を内包する。判定は **平面 (lon,lat)
  ray-casting point-in-polygon**（star-shaped を仮定しない位相正しい判定。反子午線非跨ぎ・非極前提＝(3d) までの制約）。
- **リボン位相**: 外環前半が北限界（時刻順）・後半が南限界（逆順）＝前半各点の緯度 ≥ 対応する後半点の緯度（帯の北南）。
- **非退化**: 外環は ≥3 頂点。
- **実 2024 ballpark**: 中心線全点を内包し、外環の南北端緯度が中心線の南北端より外（半影帯は umbral 帯より広い）。

### 11.6 3 領域ユニオンによる外周（式 11.6・**(3f) 確定仕様**・2026-09-14）

要確認 6 の実測（実 2024-04-08）で、部分食域は**曲線の単純連結では外周が出ない**ことが確定した。部分食域は

```
D = 帯(band) ∪ morning lune ∪ evening lune
```

の **3 領域の和**であり、morning limb の 2 枝は帯と**重なる独立ループ**を成す。よって外周は
**多角形ユニオン（クリッピング）**で得る（2026-09-14 人間決定。等高線追跡への設計差し替え・
full containment の headline 降格はいずれも不採用）。

#### (a) morning / evening の厳密分類（第一原理）

基本面 ξ に対し `dζ/dt = −μ′·cos d·ξ` なので、terminator 上の点は

| 符号 | 意味 |
|---|---|
| `ξ < 0` | ζ が増加する側＝**morning limb**（日の出） |
| `ξ > 0` | ζ が減少する側＝**evening limb**（日没） |

`cone_terminator_intersections` は測地座標しか返さないので、**ξ を併せて返す detailed 版**
（`cone_terminator_intersections_detailed` → `(GeoPoint, ξ)` 列）を足して分類する。`ξ = 0`
（測度ゼロ）は evening 側に入れる（`ξ < 0` を morning とする strict 不等号）。

#### (b) 3 領域の組み立て

いずれも **lockstep ribbon**（`hi(P1→P4 時刻順) ++ lo(P4→P1 逆順)`）で閉じる。

| 領域 | hi / lo の定義 |
|---|---|
| **帯** | (3c-iii) `trace_penumbral_limits` の北/南（昼面包絡 ELSE terminator 連結）。**現行のまま不変** |
| **morning lune** | 各サンプル時刻の terminator 交点のうち `ξ<0` のものを緯度で分け、最高緯度=hi・最低緯度=lo |
| **evening lune** | 同じく `ξ≥0` のものを緯度で分け、最高緯度=hi・最低緯度=lo |

そのサンプルに該当 limb の交点が無ければ、その時刻は当該 lune の両枝から**同時に落とす**（lockstep）。
交点が 1 点だけの時刻（接点）は hi・lo とも同一点になる（縮退を捏造しない）。頂点 3 未満の領域は捨てる。
**近似（明記）**: 同一 limb に交点が **3 点以上**ある時刻では最高緯度・最低緯度のみを採り、**中間点を捨てる**
（2 枝の緯度順序が時間で入れ替わるとリボンは自己交差するが、even-odd ユニオンが吸収する）。

**帯は自己交差しうる**（実 2024 で 4 交差・昼面包絡と terminator 連結が別 limb に載るサンプルがあるため）。
したがってユニオンは**自己交差入力を許容**しなければならない（§11.7 の選定理由）。

#### (c) ユニオンと `partial_limit`

`union_rings(&[band, morning_lune, evening_lune])` の結果（面積降順の多角形列）の**先頭＝最大面積成分**を
`partial_limit` とする。複数成分に割れた場合、2 番目以降は**落とす**（`partial_limit: Option<GeoPolygon>` は
単一多角形＝MultiPolygon 未対応・(3d) と同じ v1 制約）。実 2024 では 3 領域が相互に重なり単一成分になる。
**残る近似**として本書と conventions §11 に明記する。

#### (d) 外環頂点の正当性（11.5 の更新）

ユニオンは**交点頂点**を導入するので、「全頂点が半影縁条件を厳密に満たす」は成り立たなくなる。(3f) 以降の契約は:

- **umbra-geo 側（機械精度）**: 出力頂点は必ず**入力リングの頂点か、入力辺同士の交点**（＝入力境界上にある）。
  点を捏造しない。
- **umbra-eclipse 側**: 外環の各頂点は、ある [P1,P4] のサンプル時刻 t で**閉半影内**
  （面内距離 ≤ `|l1 − ζ·tan f1|` ＋ tol）**かつ昼面側**（`ζ ≥ −tol`）にある。
  半影縁点はこれを等号で、交点頂点は折れ線離散化の範囲内で満たす。

#### (e) リボン位相不変条件の撤廃

外環が「北 n ++ 南 n 逆順」であるという (3c-ii)/(3c-iii) の契約（頂点数が偶数・前半 i と後半 2n−1−i が
同時刻対）は、**(3f) で撤廃する**。ユニオン後の外環は入力リングの断片を繋ぎ直したもので、頂点数・順序は
入力の交差構造に依存する。位相の正しさは「中心線全点内包」「頂点が入力境界上」「単純（自己交差なし）」で縛る。

### 11.7 多角形ユニオン（`umbra-geo::union_rings`・アルゴリズム選定）

#### 選定: **平面アレンジメント方式**（辺分割 → 境界判定 → 環再結合。Weiler–Atherton 系）

検討した候補と不採用理由:

| 候補 | 不採用理由 |
|---|---|
| **Greiner–Hormann** | 退化（頂点上の交点・共有辺・接触）で破綻する。Foster–Hormann–Overfelt 拡張が要る。**自己交差入力を扱えない** |
| **Martinez–Rueda**（sweep line） | 実装は堅いが**入力が単純多角形であることを前提**にする。本件の帯は自己交差する |
| **Weiler–Atherton 原法** | 同じく退化・自己交差に弱い |
| **アレンジメント方式（採用）** | **自己交差入力を構造的に許容**する（自己交点も他リングとの交点と同列に分割点として扱う）。偶奇（even-odd）充填で membership が一意に決まり、退化は「分割後の断片を両側 membership で判定」に帰着する |

**決定的理由**: (3c-iii) の帯は実データで自己交差する。Greiner–Hormann / Martinez–Rueda はこれを前提外と
するため、前処理で帯を自己ユニオンする追加工程が必要になる。アレンジメント方式は同じ機構で自己交差を
吸収でき、工程が 1 つで済む。精度規約（部分食域は **ballpark 数十 km**・§許容誤差）では sweep line の
漸近性能（O((n+k)log n)）は不要で、素朴な O(n²) 交点列挙で十分（実 2024 で辺 ~1100 本）。

#### アルゴリズム

1. **入力正規化**: 各リングを閉じ（末尾==先頭なら重複を落とす）、連続重複点を除き、頂点 <3 のリングを捨てる。
2. **辺の列挙**: 全リングの全辺を集める。
3. **交点分割**: 全辺ペア（**同一リング内のペアも含む＝自己交差を吸収**）で線分交差パラメータ `t` を求め、
   各辺を `t` の昇順で断片に分割する。端点接触・共線重なりも分割点として登録する。
4. **量子化**: 断片端点を `SNAP`（1e-9 度）グリッドへ丸め、長さ 0 の断片を捨てる。これで端点一致が**厳密**になり、
   環の再結合が整数的に決まる。
5. **重複除去**: 無向端点対が同一の断片を 1 本に畳む（共有辺・共線重なりの退化）。
6. **境界判定**: 各断片の中点 m と法線 n̂ に対し、`m ± ε·n̂`（ε は断片長に比例・上限 1e-7 度）の
   **どちらか一方だけ**が U に属するとき、その断片を境界として採る。U の membership は
   「いずれかの入力リングの even-odd ray-casting 内部」。両側とも内部／両側とも外部の断片は捨てる
   （＝内部に埋もれた辺・完全な重複辺）。採った断片は**内部が左**になるよう向き付ける。
7'. **子午線の結線＝パリティ規則（ISSUE-051 で一般化）**: どの子午線区間が内部かは**極から数えた
   内外の反転**で決まる。極を囲まない領域は `lat=−90` が外部なので、子午線上の端点を緯度昇順に並べて
   **下から (1,2),(3,4),… を内部区間**として対にする。極を囲む領域（跨ぎ回数が奇数）はその極が内部なので、
   **端点リストの極側に極を挿入**してから同じ規則で対にする。これで偶数跨ぎと奇数跨ぎが同一規則になる。
   **「両端が同じ子午線に載る弧は自己閉じ」は誤り**（外部の帯を内部として塗り、内部の帯を落とす）。
   また本規則は**リングの向きに依存しない**ので、(3g) で導入した経度連続化による向き判定は不要になった。

7. **環の再結合**: 量子化端点をキーに、各頂点の出辺を入射辺の逆向きからの**角度で選ぶ**（最も右回り側を採る）
   ことで面を分離し、閉環を取り出す。点接触（1 頂点を共有する 2 領域）はこれで 2 つの環に分かれる。
   **pinch 分割**（2026-09-14 追記）: 角度規則は**面**の境界を辿るので、同じ面に属する 2 つの穴が 1 点で接する場合や
   穴が外環に 1 点で接する場合は、その頂点を 2 度通る自己接触環 1 本になる。閉歩行を同一頂点の再訪箇所で単純環に
   分割してから手順 8 へ渡す（`split_at_repeated_vertices`）。
8. **穴の割当**: 各環の符号付き面積（shoelace）で向きを判定し、**正＝外環／負＝穴**。各穴を、それを含む
   最小面積の外環に割り当てる。外環は面積降順で返す。外環は CCW・穴は CW に正規化する。

#### 退化ケースの方針（明記・§conventions「近似を残す箇所は明記」）

| 退化 | 方針 |
|---|---|
| **自己交差リング** | 分割段で他リングとの交差と同様に扱う。充填は **even-odd**（八の字は 2 つの領域になる） |
| **共有辺・共線重なり** | 量子化＋無向重複除去で 1 本に畳み、両側 membership で採否を決める |
| **頂点上の交点** | 量子化 SNAP により交点＝既存頂点として一致。特別扱いしない |
| **点接触（1 頂点共有）** | 角度優先の環再結合で**分離した 2 多角形**になる（内部が繋がっていないため） |
| **ゼロ面積の環** | 面積 0（|A| < AREA_EPS）の環は捨てる。捏造しない |
| **頂点 <3 のリング** | 入力段で無視 |
| **完全重複リング** | 重複除去で 1 枚分になり、元と同じ多角形を返す |

**残る近似（明記）**:
- 座標は **(lon, lat) 度の平面**として扱う（球面ではない）。**反子午線（±180）跨ぎ・極を含む領域は未対応**
  （(3d) と同じ v1 制約）。
- `SNAP = 1e-9 度`（≈0.1 mm）は、これより細かい特徴（極端に鋭い刺・1e-9 度未満の重なり）を解像しない。
  部分食域の許容誤差（ballpark 数十 km）に対して 8 桁以上の余裕がある。
- `AREA2_EPS = 1e-14`（shoelace 2 倍値）未満の面積の環は捨てる。これより細い正当な領域は落ちる。
- `CROSS_EPS = 1e-20` 以下の外積は平行とみなす。これより浅い角度で交わる辺対は交点を取りこぼす。
- `COLLINEAR_SIN_EPS = 1e-12`（隣接辺の sin θ）以下の折れは直進とみなし、中間頂点を落とす。
- **境界判定のオフセット `ε`** は、断片長の 1/4 と「中点から**他の辺までの最短距離**の 1/2」の小さい方とする
  （固定値を使うと、交差せずに近接して並走する別領域の境界辺を誤って内部と判定して捨てる）。
- **交点は辺ペアごとに 1 度だけ計算し、両辺の分割点として同じ量子化座標を共有する**。辺ごとに独立に計算すると
  同一交点が 1 ulp ずれて別キーになり、環が閉じずに結果が黙って消える（本手順の要）。
- 環が閉じずに打ち切られた歩行は**捨てる**（点を捏造しない）。上記の共有により実データでは発生しない。
- 交点列挙は **O(n²)**。経路サンプル数が 1 万点規模を超える用途では sweep line への差し替えが要る。

### 11.8 反子午線分割（**(3g) 確定仕様**・2026-09-14）

`partial_limit` は `(lon, lat)` 平面で解くため、外環が ±180 を跨ぐと経度がそのまま並び、GeoJSON 出力が
地球を一周する不正な多角形になる（§11.7 の残る近似・conventions §12）。これを **GeoJSON 出力時に**
MultiPolygon へ分割して解消する。

#### (a) 適用層＝**出力層のみ**（幾何は不変）

分割は `GeoPolygon::geojson_geometry` の内部で行う。`EclipsePath::partial_limit`（`Option<GeoPolygon>`）の
**型・値は変えない**（(3d) の `GeoLine` が MultiLineString を出力層で解決したのと同じ層に置く）。理由:

- 公開型 `Option<GeoPolygon>` を `MultiPolygon` へ広げる変更は、要確認 8 の「複数成分の切り捨て」と
  同時に行うべき公開 API 変更で、v1 の範囲を超える。
- 幾何計算（ユニオン・内包判定）は跨ぎのない連続経度表現のほうが素直で、分割は**表現の問題**である。

#### (b) 跨ぎ判定と分割（式 11.8）

外環・穴のいずれも同じ手順で扱う。閉リングの連続 2 点 `(lon1,lat1) → (lon2,lat2)` で `Δlon = lon2 − lon1` が

| 条件 | 意味 | 子午線 |
|---|---|---|
| `Δlon < −180` | 東進（+180 を越えた） | `+180 → −180` |
| `Δlon > 180` | 西進（−180 を越えた） | `−180 → +180` |

を跨ぎとする（`|Δlon| = 180` ちょうどは跨ぎとしない＝測度ゼロ境界。`GeoLine` (3d) と**同一規約**）。
跨ぎ点の緯度は子午線上で**線形補間**する（`GeoLine` と同一式）:

```
東進: t = (180 − lon1) / (360 + Δlon),  西進: t = (lon1 + 180) / (360 − Δlon)
lat_c = lat1 + t·(lat2 − lat1)
```

リングは閉曲線なので跨ぎは**偶数回**起こる。跨ぎ点で切ると東半球側・西半球側の**開いた弧**の集合になり、
各半球で「子午線上を `lat_c` 間で結ぶ」ことで閉じる（先頭の弧は末尾の弧と繋いでから切る＝閉曲線の起点は任意）。

**結線の向き（第一原理）**: 子午線上の結線は、**そのリングの実際の向き**が内部を左に保つように取る
（環向きの正規化は分割の後なので、入力の向きは CCW とは限らない・(c) 参照）。跨ぐリングの平面 shoelace は
経度が折り返して意味を持たないため、向きは**経度を連続化**（跨ぎごとに ±360 を累積）してから判定する。
以下は実際の向きが CCW（内部が左）の場合。

| 半球 | 子午線 | 内部の側 | 結線の向き |
|---|---|---|---|
| 東（`lon ≤ +180`） | `+180` | 西側（`lon < 180`）＝進行方向の左 | **北向き**（緯度が増える向き） |
| 西（`lon ≥ −180`） | `−180` | 東側（`lon > −180`）＝進行方向の左 | **南向き**（緯度が減る向き） |

したがって東側では、ある弧の終点 `lat_e` から**それより大きい弧始点のうち最小のもの**へ結ぶ。
西側では、終点 `lat_e` から**それより小さい弧始点のうち最大のもの**へ結ぶ。この規則で対応は一意に決まり、
弧を全て使い切るまで繰り返して閉環を取り出す（実際の向きが CW なら＝内部が右なので、同じ規則を反転して適用する
＝東側は南向き・西側は北向き）。

#### (c) 適用順序と出力形

**順序（重要）**: 跨ぐリングの `(lon,lat)` 平面 shoelace は `+170` と `−170` を混ぜるため**意味を持たない**。
よって環向きの正規化（外環 CCW・穴 CW）は**分割の後**に各断片へ適用する。手順は

1. 外環・各穴をそれぞれ §11.8(b) で分割する（跨がないリングはそのまま 1 断片）。
2. 各断片の環向きを正規化する（外環由来は CCW・穴由来は CW）。
3. 穴の断片を、それを含む外環断片のうち**最小面積のもの**へ割り当てる（(3f)・§11.7 手順 8 と同一規則）。
   含む外環断片が無い穴（入力が不正な場合）は**捨てる**（捏造しない）。

**出力形**: 結果が 1 枚なら `{"type":"Polygon", …}`（現行と同一・**跨がないリングの出力はバイト不変**）、
2 枚以上なら `{"type":"MultiPolygon","coordinates":[polygon, …]}`。多角形は**外環の面積降順**で並べる
（§11.7 手順 8 と同一・バイト安定な出力のため）。各リングの起点頂点は分割の切れ目に依存し、**規約しない**
（閉環として同値）。

#### (d) 残る近似（明記）

| 近似 | 内容 |
|---|---|
| 極を含む領域 | 極を囲む領域は**未対応**（(3d) から継続）。判別は**跨ぎ回数の偶奇**で行う: 閉リングの跨ぎは経度の巻き数に等しく、**奇数回＝経度が一周する＝極を囲む**。この場合は分割せず**元のリングをそのまま単一 Polygon で返す**（弧が対を成さないため閉じられない。面積を失わず・捏造もしない）。実データでは南極域の皆既（2021-12-04 は 1 回・2028-07-22 と 2037-07-13 は 3 回）が該当し、2016-03-09（2 回）は通常の跨ぎとして分割される |
| 子午線上の結線 | 子午線に沿う辺は `lat_c` 間の**直線**（測地線ではない）。子午線は大円なので測地線と一致し、誤差は生じない |
| 補間の平面性 | 跨ぎ点の緯度は `(lon,lat)` 平面の線形補間（大円ではない）。サンプル間隔（既定 60 s）での弧は短く、部分食域の ballpark 許容（数十 km）に対して無視できる |
| 子午線上の頂点 | **入力**の経度は `EastLongitude` が `[-180, 180)` へ正規化するので、頂点は `+180` を取り得ず `-180` のみ（`180° → -180°`）。`-180` の頂点は、隣接頂点が東寄り（例 `+175`）なら `Δlon = 355 > 180` ＝**跨ぎ**として扱われ、子午線上に幅ゼロの断片を生む。隣接も `-180` 近傍なら跨がない。**出力**の断片座標には `+180` が現れる（GeoJSON の生の数値であって `GeoPoint` ではない） |
| 退行リング | 頂点 2 個以下・面積ゼロのリングは分割しても面積を持たない。**捏造せず**そのまま出力する |
