## 実装レビュー（別エージェント）で発見・修正した欠陥 2 件

mutation とは別に、実装レビューが**テストが到達していない実欠陥**を 2 件指摘した。いずれも修正済み。

| 指摘 | 内容 | 修正 |
|---|---|---|
| **弧の対応付けが部分失敗すると面積を黙って失う** | 子午線上の弧を「終点から結線方向に最も近い始点」へ繋ぐ規則は、**単純リングでは正しい**（子午線上の端点は start/end が緯度順に交互に並ぶため必ず対になる）が、**自己交差リング**では対を成さない弧が出る。従来は閉じなかった歩行だけを捨てていたため、**一部の断片だけが出力され面積が失われた** | 全弧が閉環に使い切られたかを数え、`consumed != arc_count` なら**分割そのものを諦めて元のリングを返す**（極を囲む場合と同じ退避・面積を失わず捏造もしない） |
| **穴の内包判定点が凹外環で外れる** | 判定点に**頂点重心**を使っていたが、分割後の外環断片は C 字（凹）になりうるので、重心が切り欠きに落ちて `pip` が偽になり**穴が黙って捨てられる** | 判定点を**子午線から外れた穴の頂点**に変更（穴が外環に内包される限り必ず内部）。全頂点が子午線上の退行穴のみ捨てる。これに伴い `vertex_centroid` は**死コードとなり削除** |

## 死コード除去

| 箇所 | 理由 |
|---|---|
| `vertex_centroid`（5 変異） | 判定点を穴の頂点に変えたことで到達不能に |
| `geojson_geometry` の `0 => Polygon{coordinates:[]}` 分岐（1 変異） | 空入力・跨がない入力は手前の**バイト不変バイパス**で処理済みゆえ到達不能 |

## 生存変異の分類

### A. 等価変異・到達不能ガード — 許容

| 系統 | 変異 | 等価の理由 |
|---|---|---|
| 測度ゼロの跨ぎ境界 | `split_ring_at_antimeridian` / `unwrap_longitudes` の `< -180` → `<=`、`> 180` → `>=` | `|Δlon| = 180` **ちょうど**のときだけ差が出る（§11.8(b) が明示的に「跨ぎとしない」と定める測度ゼロ境界）。`GeoLine` (3d) と同一規約 |
| 退行リングの向き | `signed_area2(&r) > 0.0` → `>=`（外環・穴の正規化 2 箇所）、向き判定 `> 0.0` → `>=` | 面積**厳密ゼロ**の断片だけ差が出る。退行は反転しない規約（§11.8(d)）と整合 |
| 防御ガード | `arc.len() < 2` → `<=`/`==`、`n < 2` → `<=`/`==`（`antimeridian_crossings`）、`!used[next]` → `true`、`closed && len>=3` → `\|\|` | 構成上到達しない（弧は必ず 2 点以上・後継が使用済みなら手前の `next == start` 分岐で閉じる）。不正入力でのみ差が出る防御的分岐 |
| 同値の tie-break | 後継探索の `d < bd` → `<=` | 距離が完全一致するのは**同一緯度に始点が 2 つある**場合で、どちらを選んでも閉環は同じ |

### B. 判別テストの結果

レビュー指摘の修正後に残った**非等価**な生存に対し、判別テストを追加した（`tests/geojson.rs`）。

| 変異 | 判別テスト | 結果 |
|---|---|---|
| `ring.len() < 3` → `<= 3`（三角形を分割しない） | 反子午線を 2 回跨ぐ**三角形**の分割（補間 `t=0.5` が 2 進厳密・断片面積 +50/+150 と非対称） | **撃破** |
| 穴割当の `<` → `>`/`==`（最小面積でない外環へ） | 同一半球に**重なる 2 つの外環断片**（+1500 の鉤型・+550 の矩形）と、その重なりに入る穴 | **撃破**（`<=` は同面積 tie のみ＝等価で残存） |
| 判定点の `\|lon\| < 180` → `>`（子午線上の頂点を選ぶ） | **不要と判明**＝入力経度は `EastLongitude` が `[-180,180)` へ正規化するので `\|lon\| > 180` は構成不能。`>` では `find` が常に失敗し**全ての穴が落ちる**ので、既存の穴テスト 3 本が撃つ | **撃破**（専用テストは削除） |
| `coords.len() > 1` → `>= 1`（1 点リングを空にする） | **1 点の退行リング**が空にならないこと | **撃破** |
| `out.is_empty() \|\| consumed != arc_count` → `&&`（部分結果を返す） | 弧が対を成さない自己交差リング（6 跨ぎ） | **残存**＝下記 C |

### C. 防御ガード・到達不能 — 残存（許容）

| 変異 | 判定 |
|---|---|
| `out.is_empty() \|\| consumed != arc_count` → `&&` | **実装レビュー指摘の修正で入れた防御ガード**。差が出るのは「一部の弧だけが閉環になった」状態だが、閉リングの跨ぎは東西で対を成すため、片半球だけ閉じて他方が閉じない配置を構成できなかった（自己交差リングでも `out` が空になるか全弧が閉じるかのどちらかになる）。手動で `&&` を適用して全テストが通ることを確認済み。**面積を黙って失わないための防御**として残す（削除すればレビュー指摘の欠陥が復活する） |
| `coords.len() > 1 && …` の `>` → `>=` | 跨がない入力では手前の**バイト不変バイパス**が `self.rings` から作り直すため出力に影響しない。`==`/`<` は開/閉表現の不変性テストで**撃破**。残る `>=` は **1 点リングを含む跨ぐ多角形**でのみ差が出る二重の退行で、測度ゼロ扱いで許容 |
